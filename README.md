# ⚖️ 刑法總論學習講義：犯罪的概念與「不法推定罪責」體系

> 本專案為 4 頁刑法總論學習講義之**現代化互動網頁版**。純靜態網頁架構（HTML5 + Vanilla CSS3 + ES6 JS），**零依賴、零建置步驟**，專門為 **GitHub Pages 一鍵發布** 設計！

---

## 🌟 網頁特色

- **🎬 互動式分級影音微課播放器（3大深度版本自由切換）**：
  - 🌱 **初級版（生活情境劇入門 • 約 3~5 分鐘）**：以生活故事直觀理解「做壞事 vs 壞人」的差別，認識為什麼做壞事不一定會被處罰。
  - ⚖️ **中級版（國考與法學體系精講 • 約 8~10 分鐘）**：深入德日三階論與「不法推定罪責」兩階段架構，詳解 6 大抗辯條文要件與實務三段論答題。
  - 🏛️ **高級版（法學深究與最新憲判修法 • 約 12~15 分鐘）**：剖析規範罪責論哲學演進、2022 年刑法第 87 條監護處分重大憲政修法、民法 18 歲成年與少事法曝險行政先行跨法域連動。
  - **智慧影音功能**：支援 Web Speech API 原生中文語音旁白朗讀、動態分鏡畫布、即時字幕同步、播放倍速（1.0x / 1.25x / 1.5x）、全螢幕劇院模式與章節跳轉。
- **📖 完整分鏡製作劇本手冊 (`VIDEO_SCRIPTS.md`)**：提供專業影音分鏡腳本、視覺字卡提示、配樂建議與逐字口播劇本，可直接供 YouTube 或短影音後製剪輯使用。
- **🏛️ 現代法律科技（LegalTech）視覺設計**：精緻深色／明亮專業模式隨心切換，支援行動裝置、平板與電腦全螢幕響應。
- **🔄 兩階段審查互動流程圖**：「先評價行為（客觀壞事）➔ 經驗推定 ➔ 評價行為人（主觀壞人）➔ 反證推翻阻卻罪責」。
- **💬 6 大典型抗辯案例卡片**：
  - 模擬被告真實現況口白與律師抗辯思維。
  - 對比 2018 原書與 2024–2026 現行法最新修訂狀態（如：刑法第 87 條監護處分改革、民法 18 歲成年與少事法連動）。
  - 提供核心法條**一鍵複製條文**與即時關鍵字過濾。
- **📊 綜合比較與重點速查表**：可即時搜尋法條、罪責事由與法律效果。
- **💡 刑法思維互動測驗**：內建 3 道經典實務爭點互動題目，即時反饋詳解。
- **🖨️ 列印與 PDF 匯出優化**：隨時按下 `Ctrl + P` 即可一鍵排版輸出為清晰整潔的紙本或電子書講義。

## 🎬 如何觀看與播放分級講解影片？

本專案提供 3 種觀看與取得影片的方式：

1. **方式一：主網頁直接觀看（最推薦）**
   - 雙擊打開 `index.html`。
   - 在最上方的首頁橫幅，直接點擊金黃色按鈕 **「▶ 立即播放影片」**，頁面將自動捲動至視訊舞台並開始播放！
   - 或者直接在播放器螢幕中央點擊 **巨大發光播放按鈕 ▶**，即可開始收看 60fps 動態律法天秤動畫、即時字幕與真人感中文語音導覽！
   - 可在上方自由切換 **「🌱 初級版」**、**「⚖️ 中級版」** 與 **「🏛️ 高級版」**。
2. **方式二：獨立全螢幕放映廳 (`video.html`)**
   - 直接雙擊打開 `video.html`，享受如串流平台（YouTube/Netflix）般的純淨沉浸式大螢幕播放體驗。
3. **方式三：直接下載真實影片檔案到電腦 (`.webm`)**
   - 在播放器控制列右下角點擊 **「下載影片」** 按鈕，瀏覽器將利用 HTML5 Canvas 與 MediaRecorder 自動將當前分鏡畫面錄製並打包下載為 `.webm` 影片檔至您的下載資料夾！
4. **方式四：檢閱專業影片分鏡與錄音口播稿 (`VIDEO_SCRIPTS.md`)**
   - 若您需要自行錄影、剪輯短影音或上傳至 YouTube，可直接打開 `VIDEO_SCRIPTS.md` 取得完整鏡頭分鏡與逐字稿。
